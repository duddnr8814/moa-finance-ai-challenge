# MOA · Money On Arrival

2026 금융 AI Challenge 출품작 — 한국에 막 도착한 외국인 유학생의 **계좌 개설 전 금융 공백**을 메우는 AI 에이전트.

## 문제
국내 외국인 유학생 25만 3,512명(2025-04-01 기준, 교육부·한국교육개발원). 입국 후 외국인등록증 발급과 계좌 개설까지 보통 몇 주가 걸리고, 그동안 유학생은 더치페이·동아리 회비에서 사실상 배제된다. 함께 어울리는 한국인 학생도 현금을 받아 두거나 ATM 무통장입금을 기다려야 한다.

## 기능
| # | 기능 | 설명 |
|---|------|------|
| 1 | 모아 정산 (Settle Bridge) | 영수증 사진을 Gemini Vision이 읽어 항목별 분배. 계좌 없는 멤버 몫은 대납자에게 넘기고 장부에 이연 기록. 멤버별 모국어 정산 메시지 생성 |
| 2 | 계좌 개설 내비게이터 | 체류자격·입국일·ARC 상태를 입력하면 지금 할 일 3가지, 서류 체크리스트, 예상 소요 기간을 모국어로 안내 |
| 3 | 금융서류 통역 · 사기 경보 | 은행 서류·수상한 메시지를 해석하고 통장 대여 요구 등 사기 신호를 탐지 |

## 설계 원칙
- **자금을 이동시키지 않는다.** 정산 기록과 요청 메시지만 생성한다 (전자금융업 인가 불요 범위로 한정).
- **개인 식별정보를 수집하지 않는다.** 여권번호·외국인등록번호·계좌번호를 입력받지 않는다.
- **AI는 내장 지식베이스를 근거로만 답한다.** 근거가 없으면 "은행에 확인하라"고 답하도록 프롬프트에서 제약 (`moa/llm.py`의 `SYSTEM_RULES`).
- **AI가 죽어도 앱은 산다.** 키 미설정·쿼터 초과·네트워크 오류 시 데모 응답으로 자동 강등된다.

## 로컬 실행
```bash
pip install -r requirements.txt
export GOOGLE_API_KEY="발급받은_Gemini_API_키"   # 없어도 데모 모드로 동작
streamlit run app.py
```

## 구조
```
app.py            화면 3개 + 사이드바
moa/kb.py         지식베이스 (계좌 개설 제도, 사기 유형) — 출처·확신도 표기
moa/llm.py        Gemini 호출 래퍼 + 실패 시 데모 강등
moa/settle.py     정산 계산 (순수 함수, AI 무관)
moa/i18n.py       UI 다국어 (ko/en/zh/vi)
moa/demo.py       데모 응답
```

## 고지
시연용 MVP이며 실제 금융거래를 제공하지 않는다. 지식베이스의 제도 정보는 참고용이며, 은행별 내규는 방문 전 확인이 필요하다.
